# Prompt Quality Rubric

## 四行骨架

默认产物必须是四行：

1. `你是...` 或 `You are...`
2. `任务：...` 或 `Task: ...`
3. `约束：...` 或 `Constraints: ...`
4. `输出：...` 或 `Output: ...`

## 质量检查

### 角色行

- 必须包含明确领域和经验背景
- 禁止写成“AI 助手”

### 任务行

- 用一句话概括用户真正想达成的结果
- 不复制冗长上下文

### 约束行

- 只保留最关键的 1 到 3 条约束
- 优先保留格式、性能、合规、风格和边界

### 输出行

- 明确格式、结构或长度
- 最好能直接指导另一个模型稳定产出

## describe_prompt.md 追加规则

### 必须有

- 二级标题时间戳
- 原始需求引用块
- 模式说明
- 代码块中的四行 prompt

### 不允许

- 覆盖整个文件
- 一个节里出现多个 prompt 代码块
- 用大段解释替代 prompt 本体
